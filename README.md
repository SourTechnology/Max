# Max — Private Notes

Max is a simple note-taking app. Notes are saved in your browser on your device and are not uploaded to a server.

## Run locally

1. Save the app as `index.html`.
2. Open the file in a web browser.

No installation or build step is required.

## Features

- Create, edit, search, and delete notes
- Automatically saves changes in your browser
- Responsive layout for desktop and mobile
- Notes stay in the browser’s local storage

## Privacy and backups

Notes are stored in the browser on the current device. They do not sync between devices. Clearing browser data may permanently delete your notes, so keep a separate backup of anything important.

## Technologies

- HTML
- CSS
- JavaScript

The app is contained in one HTML file. Browsers don’t run TypeScript directly, so this version uses JavaScript.
